# Working on this repository

## UI copy

The pages show only what is needed: the data, the controls, and state such as dates,
warnings and errors. Leave out explanatory and descriptive text. Titles and labels
should explain themselves, so add no subtitles, helper lines or footnotes unless the
owner asks for one or something would otherwise be misread, and never restate a
heading or the current selection in text. Methodology belongs in the README.
